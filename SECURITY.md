# Seguridad

## Reportar una vulnerabilidad

Si encuentras un problema de seguridad en el sitio, **no abras un Issue público**. Escribe a `contacto@mineramilenium.cl` con una descripción del problema y los pasos para reproducirlo. Responderemos a la brevedad.

## Buenas prácticas del repositorio

- No subir credenciales, tokens ni llaves de API (usar variables de entorno del hosting).
- Mantener las dependencias actualizadas (`npm audit` y `npm update` periódicamente).
- Activar Dependabot y protección de la rama `main` en la configuración del repositorio.
